👻 Haunted Restaurant

Welcome to Haunted Restaurant — a spooky and interactive restaurant website designed with a mysterious and thrilling atmosphere! 🕸️🍽️

This project combines creative design, animations, sound effects, and interactive elements to provide users with a unique haunted dining experience.

📖 Project Overview

Haunted Restaurant is a creative front-end web project that provides a spooky and interactive restaurant experience through an engaging user interface.

The project uses a Halloween-inspired theme with animations, images, sound effects, and interactive elements.

✨ Features

- 👻 Spooky and haunted-themed user interface
- 🍽️ Interactive restaurant website
- 🎃 Halloween-inspired design
- ✨ CSS animations and visual effects
- 🔊 Sound effects
- 🖼️ Custom images and icons
- ⚡ Interactive JavaScript functionality
- 📱 Responsive user interface

🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, animations, and responsive design
- JavaScript – Interactive functionality
